# Portfolio (Alicando)

Scaffolded Next.js + Tailwind portfolio inspired by https://bryllim.com.

## Setup

Install dependencies and run dev server:

```powershell
cd "c:\Jesper\PROJECTS\Portfolio_Alicando"
npm install
npm run dev
```

Open http://localhost:3000

## Notes
- This is a starter scaffold using Next.js pages router and Tailwind CSS.
- Replace placeholder content and images in `public/` and `components/` to match your content.
