# Portfolio - Alicando

A modern personal portfolio website built with Next.js and Tailwind CSS. It presents a clean, responsive overview of my work, skills, and creative projects in a polished format.

## Features
- Responsive one-page portfolio layout
- Hero section and personal introduction
- Project showcase section
- Gallery and visual highlights
- Tech stack section with modern styling

## Tech Stack
- Next.js
- React
- Tailwind CSS
- JavaScript

## Run Locally
1. Clone the repository
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Start the development server:
   ```powershell
   npm run dev
   ```
4. Open http://localhost:3000

## Project Structure
- components/ - reusable UI sections
- pages/ - page entry points
- public/ - images and static assets
- styles/ - global styling

## About
This project is designed to be a professional portfolio for showcasing personal work and technical interests.
